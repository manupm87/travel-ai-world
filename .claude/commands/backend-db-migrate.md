Run or generate database migrations (Alembic). Only `core_api` owns a database.

Apply pending migrations:

```bash
just migrate
```

Create a migration after changing models in `src/backend/services/core_api/core_api/models/`:

1. Register any new model in `core_api/models/__init__.py` (Alembic discovers tables through it).
2. Generate and review:

   ```bash
   just migration "describe the change"
   # → src/backend/services/core_api/alembic/versions/<rev>_describe_the_change.py
   ```

3. Apply with `just migrate`, then confirm models and migrations agree (CI runs this too):

   ```bash
   cd src/backend/services/core_api && uv run alembic check
   ```

> Always review autogenerated files — Alembic misses column renames and some type changes.
